🚀 Project Name: Suncart

A high-performance, full-stack web application built with Next.js 15, focused on clean UI and smooth user experience.

✨ Key Features
📱 Fully Responsive: Optimized for mobile, tablet, and desktop.

🔐 Secure Auth: Email/Password and Google Login via BetterAuth.

✨ Premium Animations: Smooth interactions using GSAP & Lenis.

🎨 Modern UI: Built with Tailwind CSS, HeroUI, and DaisyUI.

⚡ Fast & SEO Friendly: Optimized using Next.js App Router.

🛠️ Tech Stack
Framework: Next.js 15 (React 19)

Styling: Tailwind CSS + HeroUI

Auth: BetterAuth

Animations: GSAP

Icons: Gravity UI & React Icons
